# Run discounts and coupons

Two different tools that are easy to confuse:

- **Campaigns** apply automatically. The shopper sees a lower price without doing anything.
- **Coupons** need a code. The shopper types it at checkout.

Use a campaign for a sale everyone should get. Use a coupon when you want to control who gets it, or
to find out where your customers came from.

## Campaigns

Campaigns *Schedule storewide, category, or product discount campaigns.* Choose the scope — the whole
store, one category, or specific products — set the discount, and set the dates.

Scheduling is the useful part: set the start and end in advance and the campaign begins and ends on
its own. No one has to remember to switch it off at midnight, which is exactly when everyone forgets.

Set the end date when you create it, even for something you intend to run indefinitely. A forgotten
campaign is a permanent price cut you are not aware of.

## Coupons

Coupons let you *Create and manage storefront discount codes.* Each has a code the shopper enters,
a discount, and usually limits — an expiry date, a usage cap, or a minimum order value.

Limits are not optional in practice. A code with no cap and no expiry will eventually be posted
somewhere public and used far more than you planned. A minimum order value also stops a coupon meant
to encourage a big basket being spent on the cheapest thing you sell.

Different codes for different places — one for your Facebook page, one for a flyer — tell you which
channel actually brings in orders.

## Check the margin first

Both tools discount the price the shopper pays; neither changes what the stock cost you. Before
setting a rate, check the margin on what you are discounting — see
[Read your reports](./read-your-reports.md). A 20% discount on a 15% margin is a sale you lose money
on, and volume makes it worse rather than better.

These affect online prices only. Counter discounts are set separately — see
[Set up discounts and tax](./discounts-and-tax.md).
